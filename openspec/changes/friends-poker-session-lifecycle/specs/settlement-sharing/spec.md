# Spec Delta

## Purpose

在本场完整结束后，为所有参与者与独立好友提供可核对、只读且固定期限的虚拟筹码结算。分享与游客身份恢复严格分离，不泄露凭证或私牌，并以实际编译包的完整好友约局流程证明各阶段能协同工作。

## ADDED Requirements

### Requirement: 最终结算固定并包含全部历史参与者
系统 SHALL 仅在全部权益结清或按批准规则统一回退后生成固定结算，列出所有在场与已离开者的昵称、补码次数、累计投入、最终归属和净盈亏；合计为零，不被后续场次或重复请求改写。

#### Scenario: 离开者与多次补码者一起结算
- **WHEN** 包含离开、重入与多次补码的本场结束
- **THEN** 最终页显示全部历史参与者及可核对数字，行数不受当前六座限制，净盈亏合计为零

#### Scenario: 未结清不得分享最终结果
- **WHEN** 本场仍有待结清权益或仅返回大厅
- **THEN** 不生成或展示伪造最终分享，本手结束待执行状态不能冒充已结算

### Requirement: 分享标识只提供独立只读访问
系统 MUST 使用不可猜测且与本场恢复证明不同的分享标识；无账号、无本机身份的独立浏览器可读取最终结算。分享入口不创建游戏连接、不读取或发送游客恢复凭证，分享标识不能用于加入、恢复或管理牌局。

#### Scenario: 独立浏览器打开
- **WHEN** 无存储身份的浏览器打开有效分享
- **THEN** 可看到固定结算，不建立游戏WebSocket，不发送恢复凭证

#### Scenario: 分享标识被当作游戏证明
- **WHEN** 使用分享标识请求恢复、补码、结束或行动
- **THEN** 请求被拒绝且本场状态不变

### Requirement: 分享页面与接口只公开结算投影
系统 MUST 只返回最终公开结算字段，不能返回原始持久记录、恢复令牌或校验信息、连接凭证、私牌、未公开牌面。昵称作为文本显示，未知分享不返回任何结算内容。

#### Scenario: 敏感数据反向扫描
- **WHEN** 用含已知恢复秘密和私牌的本场生成分享并检查HTTP响应、DOM、URL与请求
- **THEN** 不包含这些秘密或未公开手牌，只有允许的结算投影

#### Scenario: 特殊字符昵称
- **WHEN** 昵称包含HTML或脚本样式字符
- **THEN** 仅以文本显示，不执行或注入页面结构

### Requirement: 有效期固定为结束后30天
系统 SHALL 将失效时间固定为结束时间加30天；准确到期或之后时页面显示失效，接口拒绝返回结算内容。重复访问、复制、转发或重启不延长有效期；缓存不得绕过失效边界。

#### Scenario: 准确失效边界
- **WHEN** 分别在失效前1毫秒、准确失效时和之后访问
- **THEN** 前者可读，后两者失效且接口不附结算内容

#### Scenario: 重复读取与重启
- **WHEN** 分享被重复打开、复制并在服务器重启后访问
- **THEN** 结束时间、失效时间、分享标识和固定结算保持不变

### Requirement: 实际浏览器完整路径和旧玩法保持可用
系统 MUST 用实际Cocos编译包及独立浏览器身份分别验证两人、六人从邀请到多手行动、等待加入、爆零补码、离开重入、刷新断网恢复、真实服务重启回退、房主结束和分享的完整路径；保留单机、合法行动、超时、摊牌与边池回归。

#### Scenario: 两人和六人端到端
- **WHEN** 按已批准浏览器验收口径执行完整路径
- **THEN** 各阶段身份、账本、恢复与最终分享一致，保存浏览器版本、URL、构建SHA、截图、错误和资源失败记录，测试房间完成清理

#### Scenario: 单机与手机视口回归
- **WHEN** 在667×375、844×390、1280×720、1440×900视口运行单机及联机并操作新增弹窗
- **THEN** 主要操作仍至少44CSSpx，输入、旋转、模拟安全区和弹窗阻断正确，单机AI和原引擎规则不变；不把浏览器模拟说成真实手机测试
