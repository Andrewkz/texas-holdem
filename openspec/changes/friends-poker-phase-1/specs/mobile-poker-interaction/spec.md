# Spec Delta

## Purpose

让朋友在手机浏览器横屏下清楚辨认牌面与行动状态，并无需缩放页面即可完成邀请、输入昵称、出牌及恢复操作。验收关注最终显示与触摸区域、安全区和键盘变化，同时保留电脑与单机玩法；2026-10-17 用户明确批准直接在浏览器校验，本阶段以实际编译包在浏览器中的流程与手机视口模拟为验收依据；真实手机作为后续可选补充，不阻塞本阶段完成。

## ADDED Requirements

### Requirement: 手机横屏主要行动可直接操作

系统 SHALL 在手机横屏可用区域中完整显示公共牌、本人手牌、当前状态与主要行动，主要动作最终触摸区域高度不小于 44 CSS 像素；关键内容不得重叠或依赖用户缩放页面才能使用。

#### Scenario: 小尺寸手机横屏
- **WHEN** 游戏运行在 667×375 或 844×390 CSS 像素横屏视口，并扣除浏览器和设备安全区
- **THEN** 弃牌、过牌/跟注、加注及全压主操作均可直接点击，触摸区域达到规定高度，牌面与关键提示没有重叠或裁切

#### Scenario: 六人牌桌
- **WHEN** 六名真人在上述横屏尺寸中同时入座
- **THEN** 玩家可辨认自己的手牌、公共牌、筹码和当前轮到谁，其他座位不会遮挡主要操作

### Requirement: 输入与弹窗适应键盘和安全区

系统 MUST 在昵称与加注输入、键盘展开收起及安全区变化后保持确认、取消、返回操作可达；空间不足时允许明确滚动，弹层仍拦截底层操作。合法服务器地址不得被默认长度截断。

#### Scenario: 手机输入昵称
- **WHEN** 用户打开邀请入场页并展开手机键盘输入昵称
- **THEN** 其能看到当前输入内容，完成确认或取消；关闭键盘后布局恢复且不误触底层按钮

#### Scenario: 小屏加注
- **WHEN** 玩家在横屏小屏打开加注弹窗并编辑金额
- **THEN** 能看到总额与确认结果，必要时滚动到确认/取消按钮；未确认前筹码和底池不变

#### Scenario: 完整公网地址
- **WHEN** 联机地址为合法完整的同源 WebSocket endpoint，长度超过 20 字符
- **THEN** 地址保持完整，输入框不截断后缀并且能够连接对应服务

### Requirement: 状态反馈与权限一致

系统 SHALL 明确区分正在连接、正在恢复、等待下一手、轮到本人和连接已失效；禁用或等待中的动作不能提交牌局请求，反馈变化不得遮挡恢复与返回入口。

#### Scenario: 等待下一手
- **WHEN** 玩家已入座但未参与当前手
- **THEN** 页面持续显示等待下一手的提示，不呈现可点击的本人出牌动作

#### Scenario: 快速重复点击
- **WHEN** 用户在提交行动、连接或恢复期间连续点击同一主动作
- **THEN** 页面不重复提交，不重复加入或执行行动，且显示当前处理状态

### Requirement: 方向与桌面兼容

系统 SHALL 以手机横屏为主，同时保留 1280×720、1440×900 电脑视口下的既有操作和单机 AI 流程；竖屏提供可读的横屏引导，不能用强制旋转或锁屏替代布局验收。

#### Scenario: 竖屏打开邀请
- **WHEN** 用户在手机竖屏打开游戏邀请
- **THEN** 页面显示横屏体验提示并保持可返回，旋转后能继续目标房间流程，不丢失正在填写的昵称或恢复目标

#### Scenario: 电脑与单机回归
- **WHEN** 用户在电脑视口开始单机或联机并打开规则、设置、加注和返回确认
- **THEN** 核心操作仍正常，手机适配不改变单机 AI、固定盲注、底池与合法行动规则

### Requirement: 浏览器证据决定本阶段验收

系统 MUST 在实际编译包中通过浏览器验证核心横屏流程后才宣称本阶段验收完成；构建包、独立多人会话和浏览器结果必须可追溯。昵称与加注使用原生 EditBox，键盘占用可通过缩小可视区域模拟，安全区可通过页面内边距模拟，后台可通过页面冻结/恢复模拟；这些模拟不能被描述为真实手机系统行为验证。仅有静态截图或布局单元测试不足以证明流程通过。

#### Scenario: 浏览器流程验收
- **WHEN** 阶段提交浏览器验收结果
- **THEN** 结果列出浏览器版本、访问URL、构建标识、视口及邀请、昵称和加注输入、可视区域变化、旋转、模拟安全区、刷新、页面冻结/恢复和断线恢复的通过或失败情况

#### Scenario: 模拟验证范围透明
- **WHEN** 当前验收使用浏览器模拟手机条件
- **THEN** 报告明确模拟方式及未验证的系统键盘、实际安全区和操作系统后台行为；全部浏览器流程通过后允许完成第一阶段验收，不宣称真机已通过
