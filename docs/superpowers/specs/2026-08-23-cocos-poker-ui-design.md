# Cocos 德州扑克 UI 与 Pen 设计稿对齐

## 目标

将 Cocos Creator 的运行时牌桌 UI 对齐根目录 `poker.pen` 的 1280 × 720 横屏设计，同时保持现有德州规则、AI 决策、自定义加注金额校验和筹码结算不变。

## 实现方式

采用运行时重构：`assets/scripts/bootstrap/GameBootstrap.ts` 继续作为唯一的界面入口，由它创建和更新全部牌桌节点。`Game.scene` 仅保留 Canvas 与脚本挂载，`PokerEngine`、`AiController` 和 `RaiseAmount` 不承担视觉职责，也不改动其对外行为。

## 视觉系统

- 画布固定为 1280 × 720；背景为 `#0B162B`。
- 顶部状态栏使用 `#182C47`，显示 POKER CLUB、盲注/街道与六人桌说明。
- 牌桌使用 `#217E5E` 的双层椭圆结构、灰绿外圈和金色信息强调 `#F5C051`。
- 主文案使用 `#F0F9FF`；座位采用深蓝色圆角面板，本人和赢家使用金色描边。
- 卡牌有白色正面与深蓝色牌背；红黑花色清晰区分。
- 底部操作按钮固定为弃牌（红）、跟注/过牌（蓝）、自定义加注（绿）、全压（金）。

## 状态与交互

### 主牌局

- 六个座位显示昵称、筹码、当前行动，以及 D/SB/BB 标识。
- 中央展示底池、五个公共牌槽和牌堆；本人显示两张正面手牌，AI 默认显示牌背。
- 玩家可继续使用既有弃牌、跟注/过牌、自定义加注和全压交互。

### 自定义加注

- 在牌桌之上显示半透明深蓝遮罩。
- 居中弹层固定为 620 × 196，包含当前“加注至”金额、仅数字输入、−20/+20、最小/半池/满池/全压、取消和确认加注。
- 所有金额仍通过现有 `RaiseAmount` 逻辑归一化；取消不改变牌局，确认沿用现有 `handlePlayerAction`。

### 摊牌结算

- 摊牌时显示参与摊牌玩家的正面手牌与五张公共牌。
- 显示“玩家赢得金额 · 牌型”的结算提示；赢家座位使用金色描边和柔光。
- 结算筹码从底池回流至赢家座位，随后保持既有自动开始下一手的时序。

## 动效

- 发牌：牌背从牌堆飞向座位，单张 160 ms。
- AI 决策：保留 550–900 ms 的“思考中…”状态。
- 下注和结算：筹码从座位移动到中央底池，或从底池回流至赢家。
- 公共牌按街道逐张翻开；加注遮罩淡入，弹层轻微上浮，关闭时淡出。

## 测试与验收

- 为视觉令牌、座位布局和操作按钮描述创建纯函数测试；先验证测试失败，再实现最小逻辑。
- 运行 `pnpm run typecheck:game` 和 `pnpm test`。
- 使用 Cocos Creator 预览检查 1280 × 720 下：主牌局、自定义加注和结算状态都无裁切，且核心交互与金额归一化保持可用。
