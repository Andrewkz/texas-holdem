# 德州扑克 Pen 设计稿

## 目标

在 `poker.pen` 中建立与 Cocos Creator 游戏一致的 1280 × 720 横屏六人现金桌设计系统。设计稿用于明确游戏元素、交互层级和状态切换，不改变现有游戏规则或 Cocos 源码。

## 视觉方向

- 风格：深蓝背景、墨绿色牌桌、金色信息强调。
- 氛围：六人虚拟筹码现金桌，强调清晰局面信息与可操作性。
- 结构：顶部状态栏、椭圆牌桌、六个座位、中央底池与公共牌、底部操作区。
- 设计尺寸：每个状态画板固定为 1280 × 720。

## 可复用基础元素

### 视觉令牌

| 类别 | 规范 |
| --- | --- |
| 页面背景 | `#0B162B` |
| 顶部栏与弹层 | `#182C47` / `#14304A` |
| 牌桌 | `#217E5E`，外圈为灰绿，内圈浅绿描边 |
| 主强调色 | 金色 `#F5C051` |
| 主文案 | 近白 `#F0F9FF` |
| 圆角 | 状态栏 18 px；座位 16 px；按钮与输入框 8–11 px |
| 阴影 | 弹层使用深蓝黑投影，突出当前决策层 |

### 组件

1. 顶部状态栏：`POKER CLUB`、盲注与街道、桌型说明。
2. 椭圆牌桌：双层桌沿、内圈描边和居中底池区。
3. 玩家座位：玩家名称、筹码、当前位置动作和庄家/盲注标识；本人座位用金色描边。
4. 卡牌：正面与背面两种变体；红黑花色、点数与圆角白底。
5. 底池与公共牌：底池采用金色数值；公共牌容纳五张卡牌。
6. 底部操作按钮：弃牌、过牌/跟注、自定义加注、全压；采用红、蓝、绿、金功能色。
7. 自定义加注弹层：金额输入、`−20 / +20`、最小、半池、满池、全压、取消和确认加注。
8. 结算提示：赢家、获胜筹码和牌型名称；与赢家座位高亮配合。

## 状态画板

### 01 · 主牌局 / 玩家行动

- 显示六个座位、两张本人手牌、底池、轮次与盲注。
- 显示四个操作按钮：弃牌、跟注、`自定义加注` 和全压。
- AI 座位可显示“思考中…”或最近行动，留出动画标注位置。

### 02 · 自定义加注

- 以主牌局为背景，并加深蓝半透明遮罩，不丢失桌面上下文。
- 居中 620 × 196 弹层，标题为“自定义加注”。
- 当前金额显示为“加注至 180”；输入框仅接受数字。
- 提供步进、最小、半池、满池、全压、取消和确认加注。
- 只有“确认加注”进入下注流程；取消保持牌局状态不变。

### 03 · 摊牌结算

- 显示五张公共牌与参与摊牌玩家的正面手牌。
- 中央结算提示表达赢家、获胜金额和牌型，例如“你赢得 620 · 一对 K”。
- 赢家座位用金色描边和柔光强调；底池筹码指向赢家的动画方向作为注释。

## 动效标注

- 发牌：牌背从牌堆依次飞向玩家座位，单张 160 ms。
- AI 决策：显示“思考中…” 550–900 ms 后更新行动文本。
- 筹码：下注或结算时从座位移动至底池或从底池回到赢家。
- 公共牌：翻牌、转牌、河牌按街道分批翻开。
- 弹层：遮罩淡入并将弹层向上轻微浮现；取消与确认均快速淡出。

## 验收标准

- 项目根目录存在并可在 Pen 打开的 `poker.pen`。
- 文件含上述 Foundations、Components 和 3 个状态画板。
- 组件与状态画板使用一致的深蓝、墨绿、金色令牌。
- 加注弹层与结算状态完整表达当前游戏的可用交互与动画意图。
