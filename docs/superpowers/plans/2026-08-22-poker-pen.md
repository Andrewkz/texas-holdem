# Poker Pen Design Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an editable `poker.pen` design file for the 1280 × 720 six-seat Texas Hold'em game, including the main table, custom raise modal, and showdown state.

**Architecture:** Build a small visual system first (color, typography, card, seat, chip, action button, and status-bar components), then compose three state-specific artboards from those shared elements. The design file is an implementation reference for the existing Cocos `GameBootstrap` layout rather than a replacement for its code.

**Tech Stack:** Pen desktop app; editable Pen frames, groups, text, shapes, reusable components, and annotations.
